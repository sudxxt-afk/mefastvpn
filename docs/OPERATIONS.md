# Эксплуатация MeFast VPN

## Границы репозитория

В Git хранятся только исходники и шаблоны. Рабочие значения переменных,
сертификаты, private keys, Marzban volume, SQLite-база и пользовательские
конфигурации остаются на защищённом сервере или в зашифрованном хранилище.

## Перед изменением production

1. Снять off-server резервную копию SQLite, Docker volume Marzban и текущих
   конфигураций nginx/systemd. Проверить, что архив читается на другой машине.
2. Зафиксировать `systemctl status`, `docker ps`, `df -h`, `ss -ltnup` и
   `curl -fsS https://mevl.me-fast.pro/healthz`.
3. Деплоить одну компоненту за раз: backend, admin, bot или Marzban.
4. После выкладки проверить не только статус процесса, но и реальный сценарий:
   healthcheck, вход администратора, выдача тестовой подписки и клиентский
   handshake выбранного VPN-профиля.
5. При ошибке вернуть предыдущий артефакт, а не редактировать production вручную.

## Регулярные проверки

Ежедневно: статус systemd/Docker, свободное место, успешность свежего backup,
сроки сертификатов и ошибки журналов. Еженедельно: восстановление backup в
изолированной среде и ручная проверка хотя бы одного клиентского VPN-подключения.

## Backup job

`infra/scripts/backup-mefast.sh` создаёт консистентную копию backend SQLite
через SQLite Backup API и добавляет runtime-конфигурации, Marzban data и AWG
материалы в архив с правами `0600`. `mefast-backup.timer` запускает его раз в
сутки и удерживает 14 дней. Это локальная первая линия восстановления; архив
обязательно нужно реплицировать в отдельное зашифрованное хранилище — его адрес
и ключ шифрования намеренно не задаются в публичном репозитории.

## Известные зоны риска на 20 августа 2026

- Telegram-боту нужен отдельный `.venv`; его systemd unit не должен использовать
  системный Python. Backend и этот бот используют разные Telegram tokens — это
  проверяется перед их совместным запуском.
- Автоматический certbot renewal конфликтует с nginx для старых сертификатов;
  необходимо выбрать один подтверждённый способ продления и проверить активные
  домены отдельно.
- Стабильность обхода блокировок нельзя доказать каталогом протоколов. Нужны
  реальные тесты по операторам и регионам, а также независимые VPS/ASN.

## Переменные окружения

Создавайте рабочие файлы только из `infra/env/*.example`. Для production
обязательны уникальный `SPEEDY_APP_AUTH_SECRET`, настройки Marzban и отдельные
учётные данные платёжных/Telegram-интеграций, если соответствующие функции
включены.
